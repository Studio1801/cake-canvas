# CakeCanvas.co concept site

Free mockup for CakeCanvas.co (custom cakes, Rancho Cordova, CA), by Studio 1801.

One self-contained file: `index.html`. Open it in a browser, no build step.

## What is in it
- Cake designer with a live drawing, price and serving count
- Pickup calendar with daily capacity, time slots, pickup or delivery
- Inspiration photo upload
- Gallery of recent cakes ("Make one like this" loads a cake into the designer)
- Order tracking by code (try CC-0141)
- Owner ledger at `#studio`: requests, statuses, deposits, daily capacity
- Terms (`#terms`) and privacy (`#privacy`) pages

## Demo notes
- Prices and orders are samples. Orders save only in the viewer's browser.
- Cakes are SVG drawings; swap in the shop's own photos.
- A live version needs a backend for orders, payments and text alerts.
